# Folio Carousel Studio 1.3.0

Instagram carousel desktop editor with ten layouts, light and dark themes, square and portrait output, editable brand settings, image uploads, slide ordering, preview, PNG/ZIP exports, and editable project files.

Includes ten editable, six-slide Fun Tech Facts carousels, the Navy Ribbon eight-slide QR-code preset, and bundled Figma references supplied with this project. The first Open asks you to choose a folder; Folio remembers it and lists the project files there. New projects, saves, and autosaves write editable `.folio.json` files into that folder. Existing in-app projects migrate there on selection. Change folder is available in Projects and in the Open picker. Closing still saves a recovery copy.

The `main` branch contains the Windows version. The `linux` branch provides Linux desktop packaging and its release workflow. This private repository includes original reference assets; no third-party ownership or license is claimed.
