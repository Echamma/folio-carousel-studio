# Folio Carousel Studio 1.2.1

Instagram carousel desktop editor with ten layouts, light and dark themes, square and portrait output, editable brand settings, image uploads, slide ordering, preview, PNG/ZIP exports, and editable project files.

Includes ten editable, six-slide Fun Tech Facts carousels in the saved Projects list, the Navy Ribbon eight-slide QR-code preset, and bundled Figma references supplied with this project. New creates a project in the list; Save keeps it there; Open returns to saved projects. Each project retains its edits when switching or restarting. Project files can still be imported and exported as portable backups. Closing saves a recovery copy, and reopening restores the newest session.

Open now displays a searchable project picker even when the Projects tab is already selected.

The `main` branch contains the Windows version. The `linux` branch provides Linux desktop packaging and its release workflow. This private repository includes original reference assets; no third-party ownership or license is claimed.
